## 二、上传 / 更新步骤

本 Mod 已于 **2026-10-05** 首次发布（v0.5.15），`../workshop.txt` 已生成并入库。**以后每次更新照下面走**：

1. **完全退出游戏**（游戏运行时会锁住 `StacklandsProMax.dll`，部署会失败），然后依次跑：
   ```powershell
   powershell -ExecutionPolicy Bypass -File .\verify.ps1     # 离线校验：本地化 / JSON / 补丁登记
   powershell -ExecutionPolicy Bypass -File .\build.ps1      # 编译 + 部署（会清 config.json、恢复 workshop.txt 与 icon.png）
   ```
2. **抬版本号**：`manifest.json` 的 `version` + 各文档头部版本（`README` / `CHANGELOG.md` / 本文档）+ §一 第 1/7 条。
3. 启动游戏（**必须从 Steam 启动**，否则 `SteamManager.Initialized` 为假、上传会失败）→ 主菜单 **Mods** → 点列表里的 **Stacklands Pro Max**（进入它的设置页）→ 页面底部 **Upload Mod**，或直接按 **`U`**。
   > 主菜单的 Mods **列表页**本身没有上传按钮，只有 Back / Disable Mods / Open Workshop——上传入口在这一层里面。
4. 上传器页面（`ModUploadScreen`）里：
   - `Set preview image: Yes` —— 读 mod 目录里的 `icon.png`，保持 Yes；
   - `Select Tags` —— 勾 **Cards / Gameplay / Quality of Life**（页面每次打开都是空的；不勾就不会调 `SetItemTags`，工坊上原有标签保持不变，所以顺手勾上最保险）；
   - 底部 changelog 文本框 —— 写这版改了什么，可直接抄 `CHANGELOG.md` 对应版本小节；
   - 点 **Upload** → 确认弹窗会显示要上传的文件夹路径（核对一下）→ **Upload**。
5. 上传成功后游戏会用 Steam 覆盖层打开工坊条目页：
   - **把 §3.1（中文）或 §3.2（英文）粘进描述**——二选一，**别两段一起粘**：网页端才有描述字段（游戏上传器没有 `SetItemDescription`），而描述上限 8000，中英拼一起必超、报「保存标题和描述时出现错误」；
   - 需要时把可见性设为 **Public**（首传时做过了，之后保持即可）。

> ⚠️ 上传的是**整个 `Mods\StacklandsProMax\` 目录**。发布卫生靠 §一 第 2/4 条；临时放进 Mods 目录的笔记、截图上传前记得清掉。
> `icon.png`（缩略图）与 `../workshop.txt`（item id）是**有意保留**的发布资源，别删。

**首传时的一次性流程**（已做过，留档给以后开新 mod 用）：主菜单 Mods → 选中 mod → 按 `U` → 弹窗 `Create Workshop Item?` 点 `Create Item`（接受 Steam 工坊 ToS）→ 游戏在 mod 目录写入 `../workshop.txt` → **把它拷回工程根目录并入库**（`.gitignore` 不能忽略它）→ 回到上传器点 Upload。

## 六、素材来源与版权声明（发布前请过一遍）

### 6.1 本项目做了什么

| 对象 | 处理方式 | 风险 |
| --- | --- | --- |

## 七、发布后维护清单
